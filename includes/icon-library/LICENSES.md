# Icon library: sources and licenses

The files in this folder hold the icons as SVG markup, one file per icon set.
They are converted from the icon fonts listed below, or drawn for this plugin,
and keep the license of the set they come from. Do not remove these notices.

All brand logos are trademarks of their respective owners. They are included
so that site owners can link to their own profiles on those services.

## WPZOOM Icons (`socicon.php`)

Based on the **Socicon** icon font, extended and maintained by WPZOOM with
additional icons.

- License: SIL Open Font License 1.1 (https://openfontlicense.org)
- Icons added for networks the font never had (Kick, Twitch, Linktree,
  Signal and others; see `bin/icon-additions/sources.json` in the plugin's
  repository) come from **Simple Icons** (https://simpleicons.org), released
  under CC0 1.0 Universal (public domain). Only icons without a separate
  license in Simple Icons' data are used. The `website` icon is Font
  Awesome Free 7's `globe` (CC BY 4.0, see below).
- The CSS class names (`socicon`, `socicon-*`) are kept for compatibility with
  content that sites have already saved.
